# Beastman Auto Detail

Custom Beastman Auto Detail website prepared for GitHub + Vercel.

## Files
- `index.html` — homepage
- `booking.html` — interactive booking prototype
- `styles.css` — homepage styling
- `vercel.json` — simple Vercel configuration

## Deploy with GitHub + Vercel
1. Upload all files in this folder to the root of your GitHub repository.
2. Commit the files.
3. In Vercel, create/import the GitHub repository as a project.
4. Framework preset: **Other**.
5. Root directory: leave as the repository root.
6. Deploy.

## Important
The booking flow is interactive in-browser, but the calendar shown is still demo availability. Square is **not connected yet**. The next production step is a secure server/API integration with Square so availability and appointments are real.
